# Земля сегодня

Живая сводка по планете на одном экране: погода для выбранного города, космическая погода и землетрясения на интерактивном глобусе.

Весь сайт — один файл `index.html` без сборки и без ключей API. Откройте его в браузере или разверните как статику.

## Что внутри

- **Глобус** (canvas, d3-geo): землетрясения, овал полярного сияния по модели OVATION, граница дня и ночи. Вращение мышью и стрелками, масштаб кнопками, щипком или Ctrl + колесо.
- **Погода**: текущие условия, лента и графики на 24 часа (температура, осадки, ветер, УФ), прогноз на 7 дней, Солнце и Луна, сравнение с нормой за 10 лет, советы по одежде, УФ и качеству воздуха.
- **Космос**: индекс Kp с прогнозом, рентгеновский поток GOES по классам вспышек, солнечный ветер, вспышки за 3 дня, F10.7 и число пятен, шанс сияния сейчас и прогноз на ближайшую ночь.
- **Сейсмика**: счётчики за сутки, диаграмма «время × магнитуда», таблица с сортировкой и фильтрами, история сильных землетрясений региона с 1900 года.
- Тёмная, светлая и красная «наблюдательная» темы, переключение единиц, ссылка-снимок состояния, горячие клавиши (`/`, `R`, `N`, `T`), офлайн-копия последних данных.

## Источники данных

| Источник | Что берётся |
|---|---|
| [Open-Meteo](https://open-meteo.com/) | прогноз, качество воздуха, геокодинг, архив ERA5 |
| [NOAA SWPC](https://www.swpc.noaa.gov/) | Kp, солнечный ветер, GOES, F10.7, пятна, OVATION |
| [USGS](https://earthquake.usgs.gov/) | фиды землетрясений и каталог FDSN |
| BigDataCloud | название места по координатам геолокации |
| Natural Earth через `world-atlas` | контуры материков и границ |

Библиотеки подключаются с jsDelivr: Chart.js, d3-geo, d3-array, topojson-client.

## Локальный запуск

Достаточно открыть `index.html`. Геолокация и копирование в буфер в части браузеров требуют https или localhost — тогда подойдёт любой статический сервер.

Сервис информационный и не заменяет официальные предупреждения.
